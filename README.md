# Сметра

Сервис для смет, клиентских согласований и учёта заказов. Сайт и нативное Android-приложение (`ru.smetra.mobile`) используют один API и один профиль. Рабочий сайт: https://smetra.vercel.app. Android сохраняет собственный интерфейс: сервер может обновлять его тексты и синий акцент через `backend/mobile_presentation.json` без сборки APK. Новые экраны, компоненты и действия по-прежнему требуют новой версии APK.

## Что доступно

- Сметы с позициями и версиями, публичная клиентская ссылка, согласование, заказ, поступления и PDF.
- Клиенты, задачи, лиды, каталог, расходы, уведомления и поиск.
- Строительный режим: помещения, замеры, ведомость объёмов, материалы, журнал, закупки и массовое изменение расценок с предпросмотром и откатом.
- Capture превращает текст, фото или документ в редактируемый черновик сметы; на Android запрос можно передать через системное «Поделиться» или продиктовать. Неизвестные цены остаются пустыми до ввода пользователя.
- Ассистент на бесплатной модели OpenRouter: читает данные в пределах рабочего пространства и предлагает изменения, которые применяются только после подтверждения пользователя.
- Вход по почте. Подключения Яндекс ID, VK ID, Mail и Одноклассники реализованы, но включатся после настройки приложений OAuth. Привязка сервиса к существующему профилю находится в настройках сайта.
- Android поддерживает MyTracker для атрибуции VK Рекламы и продуктовой воронки. Ключ задаётся только при сборке через `MYTRACKER_SDK_KEY`; инструкция и список событий: [docs/MYTRACKER_VK_ADS.md](docs/MYTRACKER_VK_ADS.md).

Дизайн: чёрный фон, открытые поверхности вместо карточек, светло-синие действия и оригинальные 2D-иллюстрации. [Макет](docs/design/black-ui-reference.png) и исходные веб-ассеты находятся в репозитории.

## Локальный запуск

Скопируйте `.env.example` в `.env`, затем запустите `START.bat`. По умолчанию локальный сервер использует SQLite и открывается на `http://localhost:8080`. Для сборки статических ресурсов: `python scripts/build_web.py`. Для Android нужен JDK 17 и Android SDK 35: `apps\mobile\gradlew.bat -p apps/mobile assembleDebug`; по умолчанию APK обращается к рабочему HTTPS API.

## Проверки

`python -m unittest discover -s tests` проверяет API. `node tests/black_design.cjs` и `node tests/browser_flows.cjs` проверяют дизайн и полный браузерный сценарий на изолированном тестовом сервере. Android-инструментальные тесты находятся в `apps/mobile/app/src/androidTest`.

Публикация: [DEPLOYMENT.md](DEPLOYMENT.md). Подключение российских способов входа, RuStore и почты: [docs/CONNECT_SERVICES.md](docs/CONNECT_SERVICES.md). Сборка подписанного приложения: [RUSTORE_PUBLISHING.md](RUSTORE_PUBLISHING.md).

Текущий аудит и точные результаты проверок: [docs/PRODUCTION_AUDIT.md](docs/PRODUCTION_AUDIT.md) и [docs/TEST_STATUS.md](docs/TEST_STATUS.md).

Карточка приложения в RuStore доступна, но при последней проверке показывала «предзаказ». Оплата «Про» предусмотрена только на сайте; Android получает тот же доступ через общий профиль. Боевой магазин ЮKassa подключён, но контрольный платёж, webhook и чек требуют проверки. Порядок завершения настройки и ручного оформления чеков самозанятого — в [PAYMENTS.md](PAYMENTS.md). Для оплаты аккаунта с регистрацией по почте нужно также подключить подтверждающие письма.
