# Проверка действий кабинета — 6 октября 2026

Исправления опубликованы в GitHub и на `https://smetra.vercel.app`. Ответы сервера для HTML и основных JS/CSS сверены с проверенными исходниками; новая возможность API также подтверждена на production.

## Исправлено

- Убран раздел привязки сервисов из настроек. Вход через настроенные провайдеры сохранён; существующие связи аккаунтов и данные не удаляются.
- Переключатель темы меняет реальные цвета кабинета, обновляет оба переключателя и сохраняет выбор. Предпочтение применяется до загрузки стилей; чёрная тема остаётся стандартной.
- Повторная отправка обращения, удаления аккаунта, проверки оплаты, общих форм, создания диалога, записи знаний и Markdown-документа блокируется на время запроса. Ошибки сохраняют введённый текст и позволяют повторить действие.
- Кнопки тем поддержки меняют выбранную тему, сохраняя текст вопроса.
- Обновление админки корректно восстанавливает кнопку после ошибки. Повторное открытие получает свежую сводку; управление пользователем обновляет список до закрытия диалога.
- Устранён конфликт идентификаторов полей бизнеса и полей вложенных окон.
- Импорт расценок показывает соответствующий выбранному формату пример: CSV экспорта содержит копейки, таблица Excel — рубли.
- Создание и редактирование помещения правильно читают и заполняют длину: имя `length` конфликтовало со свойством коллекции полей HTML-формы.
- Журнал работ и допработы передают число работников и срок числом, как требует API. Формы объектов защищены от повторной отправки; создание открывает именно сохранённый объект.
- Кнопки открытия сметы/заказа объекта переходят в соответствующую запись.
- Отправка писем доступна в интерфейсе только при полной настройке SMTP; публичный API сообщает исключительно доступность, без параметров и секретов.

- На телефоне редактирование работы, материала, замера, журнала, закупки и допработ раскрывает свёрнутую форму до фокусировки поля.
- Действия старого диалога блокируются при загрузке другого; ветвление не меняет контекст после ухода со страницы.

`tests/dom_app_actions.cjs` запускает отдельный локальный сервер, SQLite и каталог вложений. Внешние модели, платежи, почта и производственная база не используются. Тест вызывает обработчики поставляемого интерфейса и проверяет реальные ответы API и сохранённые данные.

Пройдено **209 взаимодействий**:

- Все 19 пунктов навигации, переключение темы, боковая панель, быстрый переход, отмена и выполнение удаления тестового аккаунта, выход.
- Создание/редактирование клиентов, расценок, проектов, задач и лидов; импорт, выгрузка CSV, избранное и прочтение уведомлений.
- Редактор сметы, строки, массовая правка и отмена, локальный черновик, сохранение, публикация, клиентская ссылка и PDF.
- Запись поступления/расхода, добавление/удаление участника, дополнительные поля и настройки бизнеса.
- Поддержка, проверка статуса подписки, разделы админки, закрытие/открытие обращения, блокировка/разблокировка и выдача/отзыв Про у тестового пользователя.
- Markdown-файл: создание, просмотр, редактирование, история, восстановление и переименование.
- Диалоги и база знаний ассистента: создание, переименование, закрепление, удаление; настоящая передача SSE через API, остановка потока с сохранением текста, ветвление диалога, копирование ответа, фоновая задача и открытие сохранённого ответа.
- Объект, помещение, замер, работа, материал, факт, изменение/отмена цен, дефект, журнал, поставщик, закупка, выгрузки XLSX/PDF, допработы, ссылка и отзыв, создание/открытие сметы.

## Пределы проверки

DOM-проверка не заменяет визуальную проверку на устройстве. Доступный браузер в текущей среде отсутствует, поэтому скриншоты/анимации здесь не проверены. Все ветви состояний и все ошибки внешних сервисов этим прогоном не исчерпываются. Боевые OAuth-переходы, доставка писем, списание денег YooKassa и действия в установленном нативном APK не запускались; нативная сборка не менялась. Проверка статуса оплаты сама по себе не выдаёт бесплатную подписку.

Браузерные сценарии выполнены отдельно в GitHub Actions: [CI для b621e1a](https://github.com/neolovichstar/smetra/actions/runs/37408117969) завершился успешно. Пройдены 19 разделов при ширине 320/390/768/1440 px, сметы и публичное согласование, изменение цен, ассистент и контекст, чеки, OCR, изменение состава сметы, документы, метаданные и просмотр DOCX/XLSX/CSV. Проверены отсутствие горизонтального переполнения и ошибок браузера. Android debug/release и обе проверки lint также пройдены; release в CI проверялся без подписи.

Локальный отчёт действий: `data/qa/app-actions.json` в основном рабочем каталоге. Логи тестов находятся там же. Причина прежнего 403 — глобальный credential helper GitHub CLI выбирал другой аккаунт (`stasaleksandrov481-netizen`). Токен пользователя принадлежит `neolovichstar`; GitHub API подтвердил права `admin` и `push`. Для репозитория настроен Credential Manager и правильный аккаунт, обычная отправка проверена. Код опубликован в `main`, Vercel завершил production-развёртывание и привязку `smetra.vercel.app`.
