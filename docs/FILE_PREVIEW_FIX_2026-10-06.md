# Повторное открытие просмотра файлов

CI 37373621741 подтвердил работу браузера, потокового чата, подтверждения и отмены изменений сметы, OCR и документов. Офисный сценарий обнаружил пустой просмотр XLSX после закрытия DOCX.

Причина: браузер отправляет событие `close` асинхронно. Его обработчик очищал содержимое и прерывал запрос уже открытого следующего документа. Теперь запоздалое закрытие не освобождает ресурсы нового открытого просмотра. Ответ с ошибкой от старого запроса также не заменяет содержимое нового файла.

DOM-тест воспроизводит отложенное событие закрытия: до исправления проверка падала с `0 !== 4`, после исправления проходит. Дополнительно проверены запоздалая ошибка старого запроса, поиск, листы, сортировка, изменение ширины, скачивание оригинала и отказ в доступе. Синтаксис JavaScript и сборка web проходят.

CI больше не требует ripgrep для ожидания тестового сервера: используется доступный grep, а истечение ожидания завершает шаг с логом. Скриншоты офисного просмотра сохраняются вместе с диагностикой. Полный браузерный результат новой версии записывается после CI.

Нативный код Android не изменён; актуальный подписанный APK — 1.7.15.

Публикация этой правки пока не выполнена: подключённая GitHub-интеграция отказала в записи (`Resource not accessible by integration`), а обычный git push получил 403 для настроенного аккаунта `stasaleksandrov481-netizen`. Правка сохранена локально и перенесена в основное рабочее дерево. Production и новый браузерный запуск CI этой правкой пока не обновлены.
