# Ассистент: режим отправки и интерфейс кабинета

## Что изменилось

В web кнопка «Выполнить в фоне» раньше была отдельным действием. При пустом
поле она оставалась активной, но обработчик молча завершался. Теперь «В фоне»
выбирает режим отправки, а синяя стрелка отправляет текст в выбранном режиме.
Подсказка объясняет, что результат сохраняется в диалоге и страницу можно закрыть.

- Пустые и пробельные сообщения не отправляются. Во время сохранения заблокированы
  повторная отправка, поле и переключатель. При ошибке черновик остаётся,
  повтор того же текста использует прежний Idempotency-Key.
- Без доступного worker переключатель скрыт и заблокирован. Доступность
  проверяется до выбора режима. Квота остаётся общей с обычным чатом.
- Очередь показывает статус и кнопку открытия результата. Ошибка сохранения
  выводится рядом с полем. Ответ, пришедший после перехода на другую страницу,
  не меняет её и не удаляет новый несохранённый черновик.
- Исправлен показ скрытых элементов, включая кнопку остановки ответа.
- Во всём web-кабинете используется локальный Onest с кириллицей. Variable WOFF2
  занимает 84 040 байт, веса 100–900. Добавлены preload, font-display: swap и OFL.
  Источник: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/onest).
- Поле ввода без обводки, единая сетка кнопок 44 px, стрелка вверх, кнопка
  остановки, видимое состояние режима и короткое приветствие. На мобильных
  текст поля 16 px; пояснение фонового режима сохраняется, подсказка клавиатуры
  скрыта. Анимации учитывают prefers-reduced-motion.

В нативном Android эта итерация код и APK не меняет.

## Проверено

- 9 DOM-сценариев поля ввода: пустой текст, выбор режима и отправка, недоступный
  worker, ошибка и повтор, ответ после ухода со страницы, открытие готовой задачи,
  обычный Markdown stream, двойная отправка, скрытые элементы под реальным CSS.
- 13 DOM-сценариев асинхронной навигации и проверки безопасного Markdown/diff.
- 66 backend-тестов при запуске модулей очереди, диалогов и identity/assistant:
  OK. Включают сохранение результата после ухода, отмену, возврат квоты, повторы,
  конкурентные запросы, права доступа и подпись запуска worker. Модель подменена;
  реальные платные запросы не выполнялись.
- Ruff, JavaScript syntax, git diff --check и сборка web: PASS, 90 файлов.
- Кириллица и диапазон весов проверены в таблицах шрифта перед WOFF2-конверсией.
- Read-only диагностика production через Supabase: cron worker активен,
  расписание раз в минуту, последние записи cron succeeded. За последние два дня
  записей очереди нет. Это не доказывает выполнение конкретного запроса пользователя.

Браузер для визуального прогона в этой сессии недоступен. Существующие браузерные
сценарии обновлены под выбор режима и события ввода; проверен их синтаксис,
но сами они здесь не запускались. Полная проверка на физическом телефоне также
не выполнялась.

## Публикация

Изменения подготовлены локально. Для прямой публикации Vercel CLI не нашёл
авторизованную сессию; интерактивный вход остановлен. Последняя попытка GitHub
push в предыдущей итерации завершилась 403. Production этой итерацией не обновлён.
