# Ассистент: интерфейс разговора

Страница переработана в рамках чёрно-белого и светло-синего языка Сметры.
Основной контент — разговор. Вместо постоянно видимых переименования,
закрепления и удаления используется меню действий. Диалоги выбираются
из отдельного списка с названиями, активным состоянием и иконкой закрепления.
Меню поддерживают клавиатуру, Escape и закрытие при потере фокуса.

Поле сообщения объединяет ввод, вложения, фоновый запуск и отправку.
При стриминге кнопка остановки заменяет отправку. Убраны отдельные ряды
служебных кнопок и повторяющиеся подписи пользователя. Контекст документа
отображается компактно, без отдельной панели. База знаний использует строки.

Пустой экран содержит три конкретных стартовых действия. Существующие
стриминг, месячные лимиты, сохранение черновиков, контексты и подтверждение
изменений остаются подключены к реальным API. Добавлен безопасный рендеринг
Markdown-таблиц с прокруткой внутри ответа; HTML из ответов экранируется.

Проверки: сборка веб-ресурсов, полный браузерный бизнес-сценарий,
предпросмотр/применение/отмена AI-изменений, переименование и закрепление,
переключение диалогов через новый список, вложения и фоновые задачи.
Дополнительно проверены размеры 320/390 px, меню и Escape, расположение
инструментов в форме, Markdown-таблица и экранирование HTML.

Изменён веб-кабинет. Отдельный APK не пересобирался.
