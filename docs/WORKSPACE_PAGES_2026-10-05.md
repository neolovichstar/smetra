# Разделы кабинета: отдельные форматы, единый бренд

| Раздел | Формат |
| --- | --- |
| Сегодня | Центральный запрос и быстрые действия |
| Ассистент | Разговор, история диалогов и единое поле ввода |
| Клиенты | Алфавитный справочник с инициалами и быстрыми контактами |
| Сметы | Реестр документов с суммами, версиями и статусами |
| Проекты | Открытые строки с акцентом на состояние и бюджет |
| Задачи | Группы по состоянию и рабочее завершение/возврат |
| Календарь | Повестка, сгруппированная по дням |
| Лиды | Горизонтальный процесс без декоративных карточек |
| Расценки | Прайс со стоимостью, единицами и избранным |
| Финансы | Сводка и отдельные журналы поступлений и расходов |
| Файлы | Библиотека с форматами и действиями над файлами |
| Документы | Реестр PDF |
| Уведомления | Лента событий с акцентом на непрочитанном |
| История | Последовательная временная лента |
| Команда | Участники, роли и настройки бизнеса |
| Тарифы | Сравнение условий и история оплат |
| Поддержка | Выбор темы и отдельное поле обращения |
| Настройки | Аккаунт, способы входа и управление доступом |
| Объекты и замеры | Технический рабочий экран; длинные формы раскрываются |
| Администрирование | Операционная сводка и таблицы управления |

Бренд: чёрный фон, белый текст, светлый синий для действий и состояний.
Сохранены реальные API, права доступа, оплата и согласование изменений.
Завершение задачи передаёт revision и сохраняется сервером; ошибки и
конфликты не заменяются локальным переключением интерфейса.

Проверки: 20 разделов в изолированной тестовой базе на ширинах
320, 390, 768 и 1440 px. Нет горизонтальной прокрутки или исключений JS.
Пройдены полный бизнес-сценарий, предпросмотр/применение/отмена строительных
цен, завершение и возврат задачи, календарная группировка и темы поддержки.
`tests/browser_sections.cjs` включён в CI; админка дополнительно проверена
локально с административной ролью только у временного тестового аккаунта.

Подготовлен ручной workflow `Production deployment` для публикации
существующего проекта через GitHub Actions. Vercel-токен хранится только
в зашифрованном секрете репозитория. Настройки защиты Vercel не ослаблены.
