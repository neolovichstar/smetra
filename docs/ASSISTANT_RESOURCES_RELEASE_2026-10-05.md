# Ассистент: документы, этапы и файлы — 5 октября 2026

Ассистент умеет читать сохранённые документы, готовить PDF по смете, создавать и изменять этапы заказа, переименовывать файлы и переносить их между клиентом, сметой, заказом и строительным объектом. Изменения сохраняются только после подтверждения пользователем.

## Поведение и защита данных

- Предложение документа содержит источник, вид, шаблон, сумму и настоящий PDF для просмотра до сохранения. Скачивание сохранённого документа доступно после повторного открытия ассистента на сайте и в Android.
- Отмена создания удаляет только неизменённый документ, созданный соответствующим действием ассистента. Скачанную пользователем копию PDF отмена не удаляет.
- Переименование и перенос меняют только метаданные: содержимое и SHA-256 файла сохраняются. Расширение, пути, управляющие символы и неизвестные поля отклоняются.
- Перенос публичных вложений и файлов, используемых в дефектах, журнале и закупках, запрещён. Назначение всегда проверяется в текущем рабочем пространстве.
- Подтверждение и отмена повторяемы без дублирования результата. Проверка текущих значений предотвращает перезапись последующих ручных изменений. Для Markdown сохраняется ссылка на конкретную предыдущую версию, включая замену текста пустой строкой.
- Приватные служебные аргументы не выдаются клиенту. Данные разных рабочих пространств изолированы; наблюдатель не может выполнять изменения.
- Дополнительных таблиц и миграций не требуется. PostgreSQL использует существующий механизм транзакций и блокировок.

## Почта Яндекса

Добавлен SMTP SSL для порта 465 и проверка сертификата в обоих режимах (465 SSL, 587 STARTTLS). Инструкция подключения находится в [CONNECT_SERVICES.md](CONNECT_SERVICES.md). Реальная доставка пока не проверена: нужны адрес отправителя и пароль приложения в окружении Production. Временный режим регистрации без подтверждения не отключён.

## Проверки

- Полный backend-набор до изменения SMTP: 271 тест, один инфраструктурный тест пропущен; ошибок нет.
- Три дополнительных SMTP-теста проходят: SSL 465 с проверкой сертификата, STARTTLS до авторизации на 587, отсутствие подключения без пароля.
- Ruff, синтаксис JavaScript и сборка сайта проходят.
- Android: assembleDebug, instrumentation APK, lintDebug, lintRelease и подписанная release-сборка проходят.
- Эмулятор: создание документа, повторное открытие с кнопкой скачивания, отмена, подтверждение/отмена переименования и переноса файла проходят. Экспорт в выбранный пользователем файл отдельно не проверен этим сценарием.
- Новый мобильный браузерный сценарий включён в CI; локально не запускался. Публикация и результат CI фиксируются отдельно, не подразумеваются результатами эмулятора.

## Границы готовности

Этот выпуск закрывает конкретные инструменты ассистента. Он не подтверждает выполнение всего большого ТЗ. Остаются реальная доставка писем, проверка входа через провайдеров, контрольная оплата/webhook/возврат YooKassa, публикация RuStore и проверка на физических телефонах; полный offline и прочие отдельно запланированные функции также не входят в этот выпуск.
