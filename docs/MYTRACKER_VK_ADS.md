# MyTracker и VK Реклама для Android

В Android-приложение `ru.smetra.mobile` встроен официальный MyTracker SDK. Инициализация выполняется в `SmetraApp`, а все продуктовые события проходят через `Analytics.java`.

## 1. Получить SDK_KEY

1. Добавьте приложение в MyTracker.
2. Платформа: Android.
3. Package ID: `ru.smetra.mobile`.
4. Скопируйте `SDK_KEY` из карточки приложения.

Ключ не коммитьте в Git. Перед сборкой задайте его одним из способов:

```powershell
$env:MYTRACKER_SDK_KEY = "ВАШ_SDK_KEY"
powershell -ExecutionPolicy Bypass -File scripts/build_android_release.ps1
```

или для локальной Gradle-сборки:

```powershell
apps\mobile\gradlew.bat -p apps/mobile assembleDebug -PmyTrackerSdkKey=ВАШ_SDK_KEY
```

Если ключ не задан, приложение продолжит работать, но MyTracker не будет инициализирован.

## 2. События

В приложение добавлены события без передачи имени, email, телефона, текстов смет и других пользовательских данных:

| MyTracker event | Когда отправляется | Рекомендация для VK Ads |
| --- | --- | --- |
| Registration (встроенное) | успешная регистрация по email | категория `Регистрация` |
| Login (встроенное) | успешный вход | диагностическое событие |
| `estimate_created` | создана смета вручную или из AI Capture | ключевая продуктовая конверсия |
| `estimate_sent` | смета опубликована и готова для клиента | основная activation-конверсия |
| `client_created` | создан клиент | вспомогательная конверсия |
| `project_created` | из согласованной сметы создан проект | глубокая конверсия |
| `payment_recorded` | пользователь записал полученную от своего клиента оплату | НЕ считать покупкой Сметры |
| `ai_draft_generated` | AI успешно создал черновик | продуктовая аналитика |
| `capture_shared_in` | запрос передан в Сметру через Android Share | продуктовая аналитика |
| `pro_entitlement_activated` | Android впервые увидел активный Pro после sync | вспомогательное событие; реальную покупку лучше подтверждать S2S |

`payment_recorded` — это учёт оплаты клиента пользователя, а не покупка тарифа Сметры. Не назначайте ему категорию `Покупка` в VK Ads.

## 3. Связать MyTracker и VK Рекламу

В VK Рекламе добавьте приложение из RuStore, получите App ID и настройте интеграцию с MyTracker. Затем включите postback и назначьте категории нужным событиям. Для первой оптимизации разумно использовать `Registration`, а после накопления данных — `estimate_created` или `estimate_sent`.

## 4. Проверка перед рекламой

Соберите APK с `MYTRACKER_SDK_KEY`, установите на тестовое устройство и выполните в новой сессии:

1. регистрация;
2. создание сметы;
3. отправка сметы;
4. создание клиента.

Проверьте поступление событий в MyTracker. Только после этого используйте их как цели VK Ads. SDK буферизует события; критичные funnel-события в коде дополнительно вызывают `flush()`.

## 5. Приватность

В код событий намеренно не передаются email, телефон, ФИО, содержимое смет, названия клиентов или суммы. Используется серверный UUID пользователя как `customUserId`. После подключения аналитики перепроверьте декларацию данных в RuStore: SDK аналитики/атрибуции может относиться к данным об активности приложения и идентификаторам устройства в зависимости от фактической конфигурации и устройства.

## 6. Подтверждённая покупка Pro с backend

Для `pro_subscription_started` добавлен дополнительный server-to-server путь. Он вызывается только после того, как backend сам перепроверил платёж в YooKassa и впервые перевёл локальный платёж из `pending` в `succeeded`. Дублирующий webhook не создаёт повторную конверсию.

В production задайте:

```text
MYTRACKER_S2S_APP_ID=<числовой id приложения MyTracker>
MYTRACKER_S2S_KEY=<S2S API key>
```

`MYTRACKER_S2S_KEY` хранится только на backend. Не добавляйте его в APK, web bundle или Git. В S2S событие передаётся внутренний UUID пользователя и технические параметры `source=yookassa` и `plan`; email, телефон, данные карты и содержимое проектов не передаются.

S2S-аналитика является best-effort и выполняется после commit платёжной транзакции. Ошибка/таймаут MyTracker не отменяют подтверждённую оплату. Android-событие `pro_entitlement_activated` остаётся резервным продуктовым сигналом, но для категории `Покупка` в VK Ads используйте подтверждённое `pro_subscription_started`.
