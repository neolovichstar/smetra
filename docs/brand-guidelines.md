# Сметра: интерфейс бренда

Основной фон — чистый чёрный `#000000`. Текст — белый `#F3F4F6`.
Светлый синий `#96BEFF` обозначает главное действие, активный раздел,
фокус клавиатуры и полезные инструменты. Синяя точка логотипа — `#2684FF`.
Серый используется только для второстепенного текста и тонких разделителей.
Поверхности ввода — почти чёрные `#0B0C0E`, а не большие серые панели.

Синие заливки зарезервированы для главных кнопок. В навигации достаточно
синего текста и полупрозрачного синего выделения. Контент остаётся открытым,
без набора декоративных карточек, градиентных подложек и лишних рамок.
Иконки — единый набор Phosphor, без эмодзи.

На телефоне логотип и меню находятся в первой строке, переключатель режимов
во второй. Сенсорные действия занимают не меньше 44 px. Основной текст ввода
имеет размер 16 px, чтобы браузер не увеличивал страницу при фокусе.
Анимации короткие; настройка reduced motion отключает их.

Токены и состояния веб-кабинета находятся в `apps/web/product-ui.css`.
