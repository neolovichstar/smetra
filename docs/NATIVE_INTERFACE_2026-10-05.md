# Android: мобильный интерфейс 1.7.13

Это обновление нативных Java Views в APK `ru.smetra.mobile`, а не веб-кабинета.
Версия: `1.7.13`, versionCode `25`. API: `https://smetra.vercel.app`.

## Интерфейс

- Ассистент: закреплённые заголовок и поле ввода, отдельная прокрутка истории.
  Отправка, вложение, диалоги и фоновые задачи доступны через иконки с
  подписями для доступности и подсказками при долгом нажатии. Область нажатия — 48 dp.
- Клавиатура: учитываются её отступы; нижняя навигация скрывается на Android 11+
  во время ввода. Поле сообщения остаётся над клавиатурой.
- Сообщения: пользовательский текст выделен компактной подложкой, ответы
  ассистента остаются на открытом чёрном фоне. Поток следует за ответом,
  пока пользователь находится у конца истории.
- Во время ответа ввод заблокирован, после успеха очищается, после ошибки
  восстанавливается с черновиком. Лимит показан отдельно от кнопки отправки.
- Навигация: отдельные иконки главной и профиля, синее выделение активного
  раздела, заметная кнопка создания. Повторное нажатие активной вкладки
  не запускает загрузку данных.
- Системный синий по умолчанию обновлён до брендового `#96BEFF`;
  прежний акцент `#82B1FF` мигрирует при чтении настроек оформления.
  Другие явно настроенные акценты остаются доступны.

## Движение

Переход экранов — 240 мс. Появление элементов — 280 мс.
Меню и подтверждения используют один компонент: открытие 300 мс,
закрытие 190 мс с затуханием затемнения. Выбор выполняется после закрытия;
повторный тап во время закрытия игнорируется. Меню можно закрыть крестиком,
касанием снаружи или кнопкой «Назад». Длинное меню прокручивается.

Добавлены пульсация загрузки, плавный фокус полей и изменение доступности
отправки. Анимации отключаются при выключенном системном animator scale.
Пульсация останавливается при удалении экрана.

## Проверка

Debug/release сборки и lint проходят. Нативный `DesignSmoke` использует
отдельный локальный сервер `scripts/android_ui_fixture.py` с тестовой БД,
без доступа к рабочим данным. Он проверяет авторизацию, сметы, клиентов,
проект и оплату, сохранение черновика, расценки, диалоги и контекст,
подтверждение/отмену изменений и месячный лимит.

Режим `interfaceOnly` проверяет закрытие меню через «Назад», размер отправки,
закрепление ввода при прокрутке, фактическое открытие экранной клавиатуры,
положение поля над ней и восстановление ввода после потокового ответа.
Режим `attachmentsOnly` проверяет документы, повтор загрузки, сохранение
черновика и подготовку большого текстового файла.

APK подписан прежним сертификатом. Эти изменения требуют установки новой
версии APK: серверные настройки оформления не заменяют нативный код.
