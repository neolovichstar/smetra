# Модель угроз «сметра.» — 30 сентября 2026

Область: веб, нативный Android, Python API на Vercel, PostgreSQL/Supabase, YooKassa, российские OAuth-провайдеры и OpenRouter. Модель описывает состояние кода, а не сертификат безопасности. Метод — STRIDE: подмена личности (S), изменение данных (T), отрицание действий (R), раскрытие (I), отказ в обслуживании (D), повышение привилегий (E). Вероятность и ущерб: низкий/средний/высокий; это качественная оценка.

## Активы, субъекты и границы

Активы: аккаунты, сессии и OAuth-идентичности; персональные данные клиентов; сметы, заказы, финансовые записи и платежи; документы, файлы, публичные ссылки; административный доступ; ключи API, база данных, резервные копии и AI-учётные данные.

Субъекты: анонимный посетитель и бот, клиент с публичной ссылкой, зарегистрированный пользователь, участник/владелец пространства, администратор, злоумышленник с действующим аккаунтом, YooKassa, OAuth- и AI-провайдеры.

Границы доверия: браузер/Android/публичный клиент → API; API → PostgreSQL/хранилище файлов/YooKassa/OAuth/OpenRouter; CI/CD → production; администратор → backend. Ответы провайдеров, содержимое файла и JSON из БД нельзя считать доверенными лишь из-за источника.

## Блокирующие условия для заявления «production security ready»

Read-only снимок Production от 20 октября 2026 подтвердил, что роли `smetra_app`/`smetra_runtime` не имеют `BYPASSRLS`, а `anon`/`authenticated` не имеют доступа к закрытой схеме `smetra`. Это исправляет прежнее утверждение о том, что штатная прикладная роль безусловно обходит RLS, но не доказывает полную изоляцию всех путей: у десяти внутренних таблиц не включён `FORCE ROW LEVEL SECURITY`, а полная матрица endpoint × role × workspace ещё не проверена. Preview теперь дополнительно блокирует использование production-схемы на уровне кода. До независимой проверки изоляции, ротации ранее раскрытых секретов, перевода `YANDEX_CLIENT_SECRET` в Secret, проверки SMTP и боевых sandbox-платежей/OAuth, а также полного backup-restore drill и ASVS L2/pentest не заявлять, что защита полностью проверена.
