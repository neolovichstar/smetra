# Безопасность загрузки файлов в «Сметре»

Все загрузки в хранилище, прикрепления к смете и скриншоты поддержки проверяются до записи в базу.

## Проверки без внешнего антивируса

- У PNG/JPEG/PDF/DOCX/XLSX сверяется сигнатура файла с заявленным расширением. Название, расширение и MIME из браузера сами по себе не считаются доказательством формата.
- Для TXT/MD/CSV используется строгий UTF-8 с запретом NUL, управляющих бинарных байтов, известных сигнатур исполняемых файлов и отдельных опасных сценарных форматов. У обычного текста нет универсальных magic bytes.
- Изображения безопасно декодируются и пересохраняются без метаданных и прицепленного произвольного содержимого.
- DOCX/XLSX проходят ZIP/XML-валидацию: размеры, степень сжатия, пути, внешние связи, макросы VBA, OLE, ActiveX, исполняемые вложения, бинарные части и ZIP polyglot.
- PDF проверяется в отдельном ограниченном процессе: повреждённые документы, зашифрованные PDF и активные объекты отклоняются.
- Редактирование Markdown проходит повторную проверку текста.
- Приватные файлы и скриншоты нельзя скачивать вне разрешённого обращения или рабочего пространства.

## Антивирус

Проверка сигнатуры типа файла НЕ выявляет все вирусы. Для проверки по вирусным базам используется дополнительный ClamAV daemon, через приватный протокол INSTREAM, без промежуточного публичного хранилища.

Настройки сервера:
- CLAMAV_HOST — приватное DNS-имя/адрес clamd.
- CLAMAV_PORT=3310
- CLAMAV_TIMEOUT=8
- FILE_AV_REQUIRED=1 — обязательный режим: нет подключения, ошибки или неисправность антивируса приводят к HTTP 503, файл не сохраняется.

Не публикуйте TCP-порт ClamAV в интернете; предоставьте доступ только бэкенду. На Vercel использовать внешний приватный сервис, не запускать daemon в функции.

Без настроенного ClamAV и FILE_AV_REQUIRED=1 выполняются только проверки сигнатуры и структуры. Ни одна комбинация защит не гарантирует обнаружения абсолютно всех вредоносных файлов.

## Регрессионные тесты

Запустите: python -m unittest tests.test_file_security tests.test_support_features tests.test_vault_changelog -v

Проверить: поддельные расширения, недопустимые сигнатуры, ZIP с исполняемым вложением, повреждённые PNG/PDF, бинарный текст, скриншоты, клиентские ACL, выключенный антивирус в обязательном режиме и чистые безопасные документы. Миграцию поддержки применить до деплоя.
