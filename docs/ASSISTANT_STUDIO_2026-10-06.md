# Ассистент, знания и профиль

Переработан чат в чёрном стиле Сметры со светло-синими действиями. На мобильном экране управление сведено к компактным иконкам; текст сообщения остаётся основной частью страницы.

- Общий диалог можно переименовать, закрепить и очистить. Сохранение в отдельный диалог переносит существующие сообщения атомарно; повтор запроса использует ключ идемпотентности. Активные фоновые задачи и ответы защищены от одновременного переноса/очистки.
- Знания открываются в отдельном диалоге: личная память и знания команды разделены. Доступны добавление, редактирование, отключение и удаление записей.
- Профиль содержит необязательные имя, фамилию, профессию, компанию и описание «О себе». Настройки задают стиль ответа и включают/выключают автоматическую память.
- Инструмент `remember_knowledge` сохраняет устойчивые факты без подтверждения. Для записи требуется дословная цитата текущего сообщения пользователя. Секреты отклоняются; память ограничена 50 записями по 1500 символов. Ассистент получает ограниченный контекст профиля и памяти, а `search_knowledge` ищет личные и командные записи. Изменения финансовых/рабочих сущностей требуют подтверждения как прежде.
- Markdown использует локальный markdown-it 15.0.2: вложенные списки, нумерация с произвольного начала, цитаты, таблицы, зачёркивание, чек-листы, ссылки и незакрытые блоки кода во время стриминга. Код копируется отдельно, ответ — с исходной Markdown-разметкой. HTML не исполняется, изображения по внешним адресам не загружаются.

Миграция PostgreSQL версии 27 создаёт таблицы в закрытой схеме `smetra`, включает RLS/FORCE RLS и ограничивает доступ через `smetra_runtime`. Личная память ограничена пользователем и текущим рабочим пространством; профиль — пользователем. Миграция применена через Supabase.

Проверки: `assistant_markdown.cjs`, регрессии композера/навигации, 221 действие с изолированным API. Новый браузерный сценарий `browser_assistant_studio.cjs` проверяет меню общего диалога, окно знаний, профиль, настройки и Markdown при ширине 320/390/1440 px. Результат полного CI будет записан после выполнения.
