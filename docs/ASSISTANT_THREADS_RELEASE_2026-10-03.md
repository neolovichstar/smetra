# Диалоги и контекст ассистента: сайт и Android

## Изменения

- APK получил отдельные диалоги, создание, переименование, закрепление, удаление и ветвление с последнего ответа. Выбранный диалог сохраняется для аккаунта и очищается при выходе. Общая история и истории диалогов разделены.
- В смете, клиенте и заказе появились входы «Спросить ассистента». Приложение открывает диалог с этой записью; выбранный контекст виден и может быть удалён. Вложения, прикреплённые к диалогу на сайте, также доступны как контекст при открытии этого диалога в APK.
- Сайт сохраняет контекст в диалоге и восстанавливает его после открытия. Переключение диалога не переносит контекст предыдущей записи; снятие контекста сохраняется на сервере.
- Сервер повторно проверяет доступ к выбранной записи перед каждым запросом. Удалённый или чужой контекст отклоняется до обращения к модели и расхода квоты. `context: null` явно подавляет сохранённый контекст для запроса.
- Создание и ветвление диалогов атомарно ограничены 50 записями на пользователя в рабочем пространстве. Раньше обычное создание обходило ограничение ветвления.
- PATCH обновляет только переданные поля: одновременное закрепление не восстанавливает снятый контекст. Удалённый источник не мешает переименовать диалог или очистить ссылку на него.
- Потоковый клиент Android заканчивает чтение по событию `done`. Общий чат не делает дополнительный запрос списка диалогов, пока отдельный диалог не выбран.

## Проверка

- Локальный полный прогон: 187 Python-тестов, один пропущен; дополнительные шесть тестов диалогов прошли, включая новую конкурентную проверку снятия контекста и закрепления.
- Ruff, Markdown/diff escaping, web build: PASS (57 файлов).
- Chrome 390 px: создание диалога с контекстом сметы, повторное открытие, переименование, закрепление, снятие и переключение контекста; нет горизонтального переполнения и JS-ошибок. Сценарий включён в CI.
- PostgreSQL с production runtime RLS: создание, переименование, закрепление, очистка и удаление диалога прошли через изолированный HTTP-сервер. Временный аккаунт и его данные удалены.
- Android 35: отдельный инструментальный сценарий прошёл создание, переименование, закрепление, контекст сметы, реальный SSE через изолированный API, восстановление истории, ветвление, очистку контекста, ограничение 3 запросов в месяц и удаление диалога. Provider в fixture заменён детерминированным ответом; live-модель этим тестом не подтверждена.
- Подписанный APK 1.7.3, versionCode 15, `ru.smetra.mobile`; release lint и сборка прошли. SHA-256: `722A98F36149DB3368623EB8372090CFF0666A3BF12CD9582754454438D5608D`.

## Границы

Контекст содержит одну явно выбранную запись, не весь workspace. Поиск изображений и фоновые AI-задачи не реализованы этой итерацией. Нативное прикрепление PDF/TXT/MD прямо в чате остаётся отдельным пунктом; файлы можно прикреплять через сайт. Проверки на физическом устройстве и публикация новой сборки в RuStore не выполнены.
