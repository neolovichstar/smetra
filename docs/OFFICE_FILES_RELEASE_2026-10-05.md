# DOCX, XLSX и CSV — выпуск 1.7.15

## Добавлено

- Загрузка DOCX, XLSX и CSV в существующие файлы пространства и прямо в диалог ассистента. Файлы можно прикреплять к клиенту, смете, заказу и строительному объекту. Оригинальное содержимое сохраняется без изменений.
- Закрытый API `/api/files/{id}/preview`: текст и таблицы DOCX, листы и ячейки XLSX/CSV. Только проверенный участник текущего пространства; чужой файл возвращает 404. Предпросмотр ограничен 20 запросами в минуту на пользователя.
- Сайт: просмотр DOCX с поиском и подсветкой совпадений; таблицы с выбором листа, сортировкой, фильтрацией поиском, закреплёнными заголовками и изменением ширины столбцов мышью/касанием или клавишами стрелок.
- Android: раздел «Файлы», внутренний просмотр документов, поиск, выбор листа, сортировка по столбцу, закреплённые заголовки и настройка ширины столбцов. Оригинал можно экспортировать через системный выбор места сохранения. Из просмотра можно открыть ассистента с контекстом этого файла.
- Подготовка и индексирование новых форматов подключены к существующему фоновому worker. Разбор файла не вызывает модель и не расходует месячную квоту сообщений. После подготовки ассистент читает ограниченные фрагменты и поиск находит их содержимое.
- Нативные поля ввода теперь без обводки, включая фокус. Поиск файлов и поиск в документе сделаны однострочными; чёрный фон и голубые акценты сохранены.

## Ограничения и защита

Предпросмотр DOCX содержит текст и обычные таблицы, без полной вёрстки Word, колонтитулов и изображений. До 400 блоков и 120 000 символов. Номер источника для ассистента означает фрагмент, а не физическую страницу Word.

Предпросмотр XLSX содержит до 6 листов, 100 строк и 20 столбцов на лист. CSV — до 100 строк и 20 столбцов, UTF-8, с поддержкой BOM и разделителей запятая/точка с запятой/табуляция. Формулы представлены буквальным текстом и не вычисляются; отсутствие расчёта не выдаётся за нулевую цену. Поиск, фильтрация и сортировка выполняются по показанному фрагменту. Усечённые файлы помечены; полный оригинал доступен для скачивания.

OOXML разбирается в отдельном процессе без секретов и доступа к API. Ограничены вход, выход, время выполнения, размер распакованного архива и XML. Отклоняются макросы, ActiveX, встроенные объекты, внешние связи кроме обычных гиперссылок, шифрование, дубликаты ZIP-элементов, пути выхода из архива, чрезмерное сжатие, XML с DTD/ENTITY и несоответствие расширения структуре документа. Гиперссылки не загружаются. Вывод — структурированные строки, которые отображаются как текст; HTML пользователя не исполняется. Это не антивирусная проверка.

Новых production-зависимостей и миграций базы нет. Для DOM-тестов отдельно устанавливается jsdom 27.4.0. Яндекс ID и общий профиль сайта/Android сохраняются; SMTP в этой итерации отложен по просьбе владельца и не требуется для входа через Яндекс ID.

## Проверки

- 286 backend-тестов: ошибок нет, один инфраструктурный тест пропущен. После последней правки удаления пустых столбцов повторно прошли 12 целевых тестов офисных файлов.
- Ruff, синтаксис JavaScript, web production build (88 файлов), Android assembleDebug, assembleDebugAndroidTest, lintDebug и подписанная release-сборка проходят.
- Эмулятор: раздел файлов, DOCX с таблицей и фильтрацией текста, XLSX с буквальной формулой, выбором листа, сортировкой, поиском и изменением ширины, CSV и переход к ассистенту с контекстом проходят. Скриншоты просмотрены. Экспорт через выбранный пользователем URI отдельно этим сценарием не проверен.
- DOM-тест с настоящим результатом Python-парсера проходит: HTML отображается буквально, работают поиск/подсветка, выбор листа, числовая сортировка, изменение ширины клавишами, скачивание оригинала и обработка отказа в доступе. Это тест взаимодействий в jsdom, без запуска браузера и без проверки вёрстки.
- Браузерный сценарий добавлен в CI для mobile/desktop, поиска, подсветки, сортировки, выбора листа и ширины столбцов. Локально не запускался. В CI [37372730546](https://github.com/neolovichstar/smetra/actions/runs/37372730546) аудит зависимостей, Ruff, backend-тесты и web build прошли; браузерная часть остановилась до сценариев с ECONNREFUSED на порту Chrome 9223. В следующем коммите добавлен сбор диагностических логов. Офисный браузерный сценарий пока не подтверждён.
- Подписанное обновление 1.7.14 → 1.7.15 установлено на эмуляторе через `adb install -r`: успешно, versionCode 27, прежний сертификат подписи.

Все временные production-аккаунты и пространства удалены, удаление проверено.
