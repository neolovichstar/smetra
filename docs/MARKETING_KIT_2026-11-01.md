Цифры и утверждения ниже взяты из продукта. Не обещайте в рекламе того, чего нет.

## 2. Факты для текстов (можно использовать дословно)

- Смета с позициями, объёмами и итогами; клиент согласует её по ссылке без регистрации.
- Итог считает сервер, а не ИИ. Ассистент предлагает позиции, изменения сохраняются только после подтверждения.
- ИИ-ассистент собирает черновик сметы по описанию или фото.
- Этапы работ, поступления и расходы по каждому заказу.
- Калькуляторы плитки, ламината, краски, штукатурки и бетона; результат переносится в смету.
- 10 смет бесплатно. Тарифы: PRO Solo — 790 ₽/мес или 7 900 ₽/год; PRO Плюс — 1 490 ₽/мес; TEAM — 6 990 ₽/мес.
- Оплата разовым платежом через ЮKassa, без автопродления и скрытых списаний.
- Работает в браузере и в Android-приложении с одним аккаунтом.

Не утверждайте: «точная смета без замеров», «ИИ считает цены», число пользователей, отзывы и рейтинги, которых нет.

## 3. Ссылки с метками

Каждый канал получает свою ссылку. После регистрации метки сохраняются в аккаунте, и в админке
(«Выручка и активация» → «Каналы привлечения») видно, сколько людей пришло из канала, сколько начали работать и сколько оплатили.

Схема: `utm_source` — площадка, `utm_medium` — тип трафика, `utm_campaign` — кампания (латиницей, без пробелов).

| Канал | Ссылка |
|---|---|
| Яндекс Директ, поиск | `https://smetra.online/?utm_source=yandex&utm_medium=cpc&utm_campaign=search_smeta` |
| Яндекс Директ, калькулятор плитки | `https://smetra.online/kalkulyator/plitka?utm_source=yandex&utm_medium=cpc&utm_campaign=calc_plitka` |
| VK Реклама | `https://smetra.online/?utm_source=vk&utm_medium=cpc&utm_campaign=<название>` |
| Пост в сообществе VK | `https://smetra.online/?utm_source=vk&utm_medium=social&utm_campaign=<дата_или_тема>` |
| Telegram-канал / посев | `https://smetra.online/?utm_source=telegram&utm_medium=post&utm_campaign=<канал>` |
| Авито (объявление об услуге) | `https://smetra.online/?utm_source=avito&utm_medium=listing&utm_campaign=<город>` |
| Рассылка | `https://smetra.online/?utm_source=email&utm_medium=newsletter&utm_campaign=<выпуск>` |
| Блогер / партнёр | `https://smetra.online/?utm_source=<ник>&utm_medium=influencer&utm_campaign=<запуск>` |

Клики из Яндекс Директа и Google Ads без меток тоже распознаются по `yclid`/`gclid`.
Переходы из поиска и с других сайтов попадают в отчёт как «поиск: yandex.ru», «сайт: forumhouse.ru» и т. п.

## 4. Тексты объявлений (черновики)

**Поиск, «программа для смет»**
- Заголовок: Сметы для ремонта за минуты
- Текст: Позиции, объёмы и итог. Клиент согласует по ссылке. 10 смет бесплатно.

**Поиск, «калькулятор плитки»**
- Заголовок: Калькулятор плитки онлайн
- Текст: Площадь с запасом и число упаковок. Перенесите расчёт в смету клиенту.

**VK / Telegram**
> Смета, которую клиент понимает. Позиции и итог на одной странице, согласование по ссылке, этапы и оплаты по заказу. ИИ-ассистент соберёт черновик по описанию — а сумму посчитает сервер, без ошибок в итогах. Первые 10 смет бесплатно → smetra.online

## 5. Чек-лист перед запуском трафика

- [ ] Выкатить текущую ветку на прод (миграции 65 и 66).
- [ ] Яндекс Вебмастер: подтвердить smetra.online (метатег или файл — пришлите код, добавлю), отправить `https://smetra.online/sitemap.xml`.
- [ ] Google Search Console: то же самое.
- [ ] Яндекс Метрика: создать счётчик и прислать номер. Для подключения нужно разрешить `mc.yandex.ru` в Content-Security-Policy; это сетевое изменение, делаем по согласованию.
- [ ] Проверить превью ссылки: отправить `https://smetra.online` себе в Telegram.
- [ ] Завести ссылки с метками из раздела 3 для каждого канала.
- [ ] Через неделю открыть «Каналы привлечения» в админке и сравнить каналы по доле оплат, а не по числу регистраций.

## 6. Что видно в продукте после запуска

- **Админка → «Выручка и активация»**: воронка, когорты, каналы привлечения с регистрациями, активацией и оплатами.
- **Логи Vercel**: строки `"event": "client_error"` — ошибки JavaScript у реальных пользователей (только наши скрипты, без персональных данных в адресах).
- **«Что нового»** в кабинете: публикуйте обновления в Markdown и смотрите просмотры и реакции — это готовый повод для поста в соцсетях.
