# Первая версия Android-приложения для RuStore

У приложения `ru.smetra.mobile` сейчас оформлен предзаказ, но установочный файл ещё не загружался. Поэтому сертификата предыдущей версии нет. Первый релизный ключ создан локально в `%USERPROFILE%\.smetra\android\release.p12`; его отпечаток SHA-256 записан в `signing.json` рядом с ключом. Ключ и пароль не входят в Git или APK.

Готовый подписанный файл: `dist/smetra-mobile-1.6.0-release.apk` (`versionCode 10`, `versionName 1.6.0`). Эта версия сохраняет нативный интерфейс. Тексты входа и главного экрана и синий акцент можно менять в `backend/mobile_presentation.json` с последующей публикацией сервера, без новой сборки APK. Для новых экранов и действий нужен новый APK. Файл `1.5.0` с веб-оболочкой использовать не нужно. Для повторной сборки на этом компьютере: `powershell -ExecutionPolicy Bypass -File scripts/build_android_release.ps1`. Скрипт запускает release lint, собирает минифицированный APK, проверяет пакет, версию, подпись и совпадение отпечатка с сохранённым сертификатом. Пароль автоматически расшифровывается средствами Windows только в текущей учётной записи.

Контрольная сумма APK 1.6.0 (SHA-256): `1AD25F143546EBC15E2597F48F475BE725ADFC46AF61B2B7824C32745C4ED6C0`. Сертификат подписи проверен локальным скриптом; новая версия ещё не проверялась на устройстве и не загружена в RuStore.

**До отправки первой версии сохраните вне компьютера сам `release.p12` и его пароль в надёжном хранилище.** Файл `password.dpapi` расшифровывается только в этой учётной записи Windows и не заменяет отдельную резервную копию пароля. Получить пароль для переноса в менеджер паролей можно локально командой `powershell -ExecutionPolicy Bypass -File scripts/show_android_signing_password.ps1`; не запускайте её в общих логах и не отправляйте пароль в чат. Для будущих обновлений используйте именно этот ключ.

В RuStore Консоли откройте приложение из предзаказа и загрузите первую версию как APK. Убедитесь, что package name предзаказа — `ru.smetra.mobile`. По [правилам RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/preorder) первая версия после предзаказа публикуется вручную или по расписанию после модерации. Сверьте иконку, скриншоты, описание, контакты разработчика и политику данных перед отправкой. После принятия первой версии следующие APK должны иметь больший `versionCode` и ту же подпись.

Сайт и Android используют `https://smetra.vercel.app`; кнопка RuStore указывает на https://www.rustore.ru/catalog/app/ru.smetra.mobile. Платёж за тариф «Про» проводится только на сайте после подключения магазина ЮKassa, не внутри Android-приложения.
## Следующая сборка 1.6.1

Исходники Android обновлены до `versionCode 11` / `versionName 1.6.1` и содержат интеграцию MyTracker для VK Рекламы. Эта сборка в текущем окружении **не собиралась**, поэтому APK 1.6.1 и его SHA-256 здесь не заявлены как проверенные. Перед локальной release-сборкой задайте `MYTRACKER_SDK_KEY` по инструкции [docs/MYTRACKER_VK_ADS.md](docs/MYTRACKER_VK_ADS.md), затем запустите `scripts/build_android_release.ps1`. Скрипт теперь ожидает именно 1.6.1/11.
