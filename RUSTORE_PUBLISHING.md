# Публикация Android-приложения в RuStore

Текущий релиз: **2.2.0 (46)**, пакет `ru.smetra.mobile`, API `https://smetra.online`. Приложение использует WebView с тем же аккаунтом и серверной авторизацией, что сайт; резервные нативные экраны сохранены.

Изменения: ограниченный гостевой режим, компактный телефонный интерфейс, RuStore Review 10.5.2, прямой VK Ad SDK 5.52.5 и восстановление заработанной награды после обрыва/перезапуска. Подробности и проверки: [MOBILE_2_2.md](./docs/MOBILE_2_2.md).

## Получение APK

На прежнем Windows-профиле с сохранённым ключом:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_android_release.ps1
```

Скрипт выполняет release lint и минификацию, проверяет пакет, версию, подпись и совпадение SHA-256 сертификата с локальным `signing.json`. Результат: `dist/smetra-mobile-2.2.0-release.apk`. Не создавайте другой ключ для обновления. Локальный ключ хранится в `%USERPROFILE%\.smetra\android\release.p12`, пароль защищён DPAPI для этой учётной записи Windows. Они не входят в Git, APK или web-сборку.

Перед сборкой при необходимости задайте публичные идентификаторы `MYTRACKER_SDK_KEY` и `RUSTORE_PUSH_PROJECT_ID`. Без них аналитика и Push соответственно отключены; основные функции работают. Серверные ключи в приложение не добавляйте.

## Загрузка в магазин

1. Разверните совместимые web/backend-изменения. Новых миграций базы для этого релиза нет.
2. Загрузите подписанный APK в **существующее** приложение `ru.smetra.mobile` в RuStore. Сверьте версию 2.2.0 (46), SHA-256 APK и прежний сертификат. Не загружайте debug APK из локальных QA-проверок.
3. Актуализируйте описание обработки SDK-данных и гостевого режима. Страница конфиденциальности: `https://smetra.online/privacy`.
4. Установите сборку из RuStore и проверьте вход, сохранение обычной сметы, PDF/XLSX, отзыв и добровольное видео. Магазин сам определяет доступность окна отзыва.
5. Реклама требует вашего допущенного блока VK; инструкция для самозанятого в РФ: [VK Rewarded Ads](./docs/monetization/vk-rewarded.md).

Успешная локальная сборка не означает публикацию в RuStore, прохождение модерации или подключение выплат. Политика обновлений и тарифные ограничения остаются серверными. Для следующего обновления увеличивайте versionCode; APK с меньшим номером поверх опубликованного не устанавливается.
